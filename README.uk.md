# AI Limits

Маленький нативний floating-віджет для Windows 11, що показує ліміти
використання AI-провайдерів прямо на робочому столі: **Claude**,
**OpenAI Codex**, **GitHub Copilot**, **Google Antigravity**.

## Чому цей віджет

Кожне твердження нижче — виміряне або перевірюване, без маркетингу.

- **Безпечний за дизайном.** Він лише **читає** токени, які офіційні
  CLI-інструменти вже зберігають на твоїй машині — ніколи не оновлює і не
  ротує їх, тож не може тебе розлогінити. Твої власні ключі (якщо додаси)
  живуть лише у **Windows Credential Manager**. Без телеметрії: звертається
  тільки до endpoint'ів самих провайдерів.
- **Автономний, поки ти працюєш.** Щоденна робота з CLI сама тримає токени
  свіжими — віджет показує живі дані без налаштувань і власних логінів.
- **Фактично нульове навантаження — проаудитовано, а не заявлено.**
  Виміряно на запущеному застосунку: **0.024% одного ядра CPU**, **нуль
  використання GPU** (CPU-рендеринг), ~60 МБ RAM, без підняття роздільності
  таймера, ~3 МБ exe. Відтвори сам: `bench/perf_audit.ps1`; повні цифри в
  [docs/uk/ARCHITECTURE.md](docs/uk/ARCHITECTURE.md#споживання-ресурсів-виміряно-не-оцінено).
- **Чесні дані.** Застаріле значення сіріє і показує давність; гарантовано
  скинуте вікно — оцінку `≈0%`. Він ніколи не вигадує цифри.
- **Самодостатній.** Статично злінкований — без Visual C++ Redistributable,
  без вкладених DLL. Інсталятору не потрібні права адміністратора.

## Встановлення

Завантаж `AiLimits-Setup-<версія>.exe` зі сторінки
[Releases](https://github.com/napxlexn/ailimits/releases) і запусти.
Права адміністратора не потрібні (ставиться у `%LOCALAPPDATA%\AiLimits`).
Опційно під час встановлення: автозапуск із Windows, ярлик на робочому столі.

> Інсталятор **не підписаний** цифровим підписом, тож Windows SmartScreen
> може показати «Windows захистила ваш ПК». Натисни **Докладніше → Все одно
> виконати**. Завантаження можна звірити з SHA-256, опублікованим у релізі.

Інсталятор ставить чисту програму — без ключів і токенів; при першому
запуску віджет сам знаходить джерела авторизації, описані нижче.

## Швидкий старт

1. **Запусти.** При першому старті він тихо знаходить CLI, якими ти вже
   користуєшся — Claude Code, Codex, `gh`, Antigravity CLI і підтримані
   legacy-сеанси Gemini CLI — і одразу показує живі ліміти. Без логіну й
   налаштувань.
2. **Постав на місце.** Тягни лівою кнопкою; **Shift** під час перетягування
   магнітить до найближчого краю екрана; `Lock position` (ПКМ) фіксує.
3. **Обери вигляд.** ПКМ → рівень деталізації (Compact / Medium / Expanded),
   орієнтація смужок (Vertical / Horizontal), палітра (монохром або 8 кольорів),
   прозорість / яскравість / насиченість — як на скрінах вище.
4. **Наведи курсор на рядок провайдера**, щоб замість часу скидання побачити
   його тижневий ліміт. Сірий або `≈`-рядок натомість пояснює себе під
   курсором — причина і що зробити (напр. `token expired — run Claude Code`).
5. **Граєш чи повний екран?** ПКМ → **Indicator** → *Panel* або *Tray*
   лишає використання на панелі завдань, поки overlay прихований чи
   перекритий — див. [Індикатор на панелі завдань](#індикатор-на-панелі-завдань).
6. **Лівий клік по трей-іконці чи панелі** виносить віджет на передній план
   (або ховає); **правий клік будь-де на панелі** — те саме меню.

## Як працює авторизація

Віджет ніколи не просить логінитись. Він моніторить ліміти **підписок**,
повторно використовуючи токени, які офіційні CLI тримають на твоїй машині,
строго read-only:

| Провайдер | Автоматичне джерело (за замовчуванням) | Щоб увімкнути |
|---|---|---|
| Claude | `%USERPROFILE%\.claude\.credentials.json` (OAuth-токен Claude Code) | запустити [Claude Code](https://claude.com/claude-code) хоч раз |
| Codex | `%USERPROFILE%\.codex\auth.json` (токен Codex CLI) | один раз `codex login` |
| Copilot | `gh auth token` (GitHub CLI) | один раз `gh auth login` |
| Antigravity | Windows Credential Manager target `gemini:antigravity`; fallback `%USERPROFILE%\.gemini\oauth_creds.json` | запустити Antigravity CLI хоч раз або мати ще підтриманий Gemini CLI flow |

Це короткоживучі **OAuth access tokens**; CLI-власник оновлює їх щоразу,
коли ти ним користуєшся. Віджет ніколи не оновлює їх сам — OAuth-refresh
ротує токен і розлогінив би CLI.

### Скільки дані лишаються точними без жодних дій

| Провайдер | Живі дані тривають | Після цього |
|---|---|---|
| **Claude** | ~8 годин після останнього сеансу в Claude Code (реальний час життя токена) | відкат до `statusline.jsonl`, інакше останнє значення сірим |
| **Codex** | поки активно користуєшся Codex CLI (його токен коротший) | останнє значення сірим, із давністю |
| **Copilot** | **нескінченно** — gh тримає токен свіжим, поки ти залогінений | — |
| **Antigravity** | поки Antigravity CLI оновлює keyring token або підтриманий Gemini CLI flow оновлює `oauth_creds.json` | останнє значення сірим, із давністю |

Google припинив обслуговувати Gemini CLI для individual, Google AI Pro і
Google AI Ultra користувачів 18 червня 2026 року. Для них шлях міграції —
Antigravity CLI; віджет читає token Antigravity із Windows Credential Manager
перед fallback (відкатом) до legacy-файлу Gemini CLI.

**У Claude є серверна стеля свіжості:** Anthropic обмежує usage-endpoint
(HTTP 429, `Retry-After: 0`, перевірено 2026-07-09), а per-token бакет
ділиться з опитуванням самого Claude Code — тож поки Claude Code активний,
оновлення Claude інколи займає 2–3 хвилини навіть на 1-хвилинному
інтервалі. Невдалий цикл повторюється за хвилину; решти провайдерів це не
стосується.

Протухлий токен Claude/Codex ніколи не означає неправильних цифр: останнє
значення лишається сірим із давністю, гарантовано скинуте вікно показує
`≈0%`, а відлік до скидання тікає локально. Користуйся CLI щодня — і живі
дані будуть майже весь час.

### Ручна авторизація (для незалежності або без CLI)

Для сетапів без CLI або облікових даних, що не залежать від активності CLI.
Що реально вартий кожен варіант:

| Провайдер | Ручний варіант | Звідки взяти | Показує те саме, що підписка? |
|---|---|---|---|
| **Copilot** | Personal Access Token (можна безстроковий) | github.com/settings/tokens → *Generate new token* | **так** — справжнє «постав і забудь» |
| **Claude** | API ключ | console.anthropic.com → Settings → API Keys → *Create Key* (`sk-ant-…`) | **ні** — це ліміти твого **API-акаунта**, а не % підписки Pro/Max |
| **Codex** | — | (окремого стабільного токена нема; usage-токен — це той самий короткоживучий OAuth) | — |

**Як додати облікові дані — два способи:**

1. **З буфера обміну (найпростіше).** Скопіюй ключ/токен, ПКМ на віджеті →
   **Providers** → провайдер → відповідний пункт `Paste … from clipboard`
   (*Copilot*: PAT; *Claude*: API ключ — перемикає метод — або usage-токен,
   що пробується перед автоматичним; *Codex*: usage-токен). Тост
   підтвердить; секрет одразу йде в Credential Manager.
2. **З терміналу** — `ailimits-auth.exe` лежить поруч із віджетом
   (`%LOCALAPPDATA%\AiLimits`):
   ```
   ailimits-auth status                       # показати всі виявлені джерела
   ailimits-auth set copilot                  # зберегти PAT (прихований ввід)
   ailimits-auth set claude                   # зберегти API ключ Claude
   ailimits-auth set-usage-token claude|codex # зберегти ручний usage-токен
   ailimits-auth remove copilot|claude
   ailimits-auth remove-usage-token claude|codex
   ```
   `set-usage-token` спершу робить один запит до usage-endpoint'а провайдера
   і зберігає токен лише якщо його прийнято.

**Повернутися до автоматики:** видали ключ із меню (`Remove key`) або CLI —
провайдер повернеться на джерела підписки.

## Контекстне меню

ПКМ на віджеті: рівень деталізації (Compact / Medium / Expanded), лейаут
(Vertical / Horizontal), `Lock position` і `Always on top` (два незалежні
перемикачі), Palette (монохром + 8 кольорів), Background opacity, Brightness,
Saturation, Forecast (burn-rate «~час до ліміту», вимкнений за
замовчуванням), Update interval (1 / 5 / 15 / 30 хв), `Automatic updates`
(тихе фонове самооновлення, увімкнено за замовчуванням), Indicator,
налаштування провайдерів, Quit.

### Індикатор на панелі завдань

Навіть коли overlay прихований або перекритий повноекранною програмою,
компактний показник використання лишається видимим. ПКМ → **Indicator**:

- **Tray icon** — одна 16px іконка-пиріг у системному треї з найвищим
  поточним %.
- **Panel (rows / grid)** — прозорий overlay поруч із годинником: без вікна
  чи прямокутника, лише цифри розміру годинника й смужки поверх таскбару.
  Монохромний, слідує системній світлій/темній темі, показує перші два
  провайдери в порядку віджета і стежить за таскбаром наживо
  (авто-приховування, роздільність, ширина трея). **При наведенні** —
  tooltip у стилі системних, з усіма провайдерами. Коли **Пуск / Пошук** чи
  auto-hide бар перекриває панель — індикатор перемикається на
  іконку-пиріг у треї й сам повертається; коли екран займає **повноекранний
  застосунок** (гра, браузер по F11) — панель ховається разом із таскбаром і
  повертається, щойно ти alt-tab-нешся на робочий стіл.
- **Off** — без індикатора.

Якщо Windows показує таскбар на більш ніж одному дисплеї, **Indicator →
Display** вибирає, до якого таскбару кріпиться панель. Це підменю з'являється
лише коли існує другий таскбар; якщо обраний дисплей потім зникає (від'єднано),
панель повертається на основний таскбар.

Лівий клік по іконці трею чи по панелі виносить віджет на передній план (або
ховає, якщо він уже спереду, зверху); правий клік **будь-де на панелі**
відкриває це саме меню.

## Конфіг і діагностика

`%APPDATA%\AiLimits\config.toml` — створюється автоматично; кожна зміна з
меню зберігається туди. Довідник формату: [docs/uk/CONFIG.md](docs/uk/CONFIG.md).

Задай `AILIMITS_LOG=ailimits=debug` або `RUST_LOG=ailimits=debug` —
діагностичний лог писатиметься у `%APPDATA%\AiLimits\ailimits.log` (stderr у
GUI-застосунку невидимий).

# Rust 1.86+, Windows 11
