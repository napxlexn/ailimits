FAQ

Questions people actually ask

How do I check my Claude Code session and weekly limit?

Install AI Limits and log in to Claude Code as usual. The widget reads the Claude Code login on your machine and shows the 5-hour session, the weekly window and the Opus and Sonnet pools with live percentages and reset countdowns. Nothing to configure.

Does it need API keys?

No. It reads the logins your CLI tools already have: Claude Code, Codex CLI, the gh CLI and Antigravity. The tokens are used read-only and never rotated, so your tools stay logged in. API keys are an optional extra path, stored in Windows Credential Manager, never in a config file.

Which providers are supported?

Claude (Anthropic), OpenAI Codex via a ChatGPT subscription, GitHub Copilot including premium requests, and Google Antigravity. Each one can be toggled from the context menu; disabled providers make no network requests.

Does it slow the PC down?

The numbers above are from an automated audit of the released build: about 0.005% of one CPU core, zero GPU engine use, around 37 MB of RAM, no raised timer resolution. Polling pauses entirely when you are away from the keyboard.

Is it free?

Yes. Open source under GPL-3.0; the code, releases and issue tracker live on GitHub.

What does the tray icon show?

Two concentric rings: the busiest provider on the outer ring, the runner-up inside, both sweeping clockwise from 12 o'clock. There is also a taskbar mini panel with clock-sized digits, or you can turn the secondary indicator off.
