Questions people actually ask

How do I check my Claude Code session and weekly limit?

Install AI Limits and log in to Claude Code as usual. The widget reads the Claude Code login on your machine and shows the 5-hour session, the weekly window and the weekly Opus and Sonnet windows with live percentages and reset countdowns. Nothing to configure.

Does it need API keys?

No. It reads the logins your CLI tools already have: Claude Code, Codex CLI, the gh CLI and the Antigravity CLI session. The tokens are used read-only and never rotated, so your tools stay logged in. API keys are an optional extra path, stored in Windows Credential Manager, never in a config file.

Which providers are supported?

Claude (Anthropic), OpenAI Codex via a ChatGPT subscription, GitHub Copilot including premium requests, and Google Antigravity. Each one can be toggled from the context menu; disabled providers make no network requests.

Does it slow the PC down?

Measured, not estimated: an automated audit of the release build records about 0.005% of one CPU core, no GPU engine time at all, a working set around 37 MB and no raised timer resolution. Polling pauses after five minutes without input, and while the workstation is locked.

Is it free?

Yes. Open source under GPL-3.0; the code, releases and issue tracker live on GitHub.

Does it show GitHub Copilot premium requests?

Yes. The Copilot rows show the premium requests, chat and completions quotas with the date each one resets, read from the same endpoint the Copilot extensions use.

What does the tray icon show?

Two concentric rings: the busiest provider on the outer ring, the runner-up inside, both sweeping clockwise from 12 o'clock. A value too small for an arc becomes a dot, and only a true 100% closes the ring, so the shape never lies. It is one of two indicators: the alternative is the taskbar panel, which paints the first two providers onto the bar as digits and bars instead. You pick one from the Indicator submenu.
