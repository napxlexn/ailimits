Know your limits. Before they know you.

A native acrylic widget for Windows 11 that shows how much of your Claude, Codex, Copilot, Antigravity, Grok and Cursor limits you have used, and when every window resets. It reads the logins your tools already have once you allow it, and Cursor gets a sign-in of its own. No API keys required.

Questions people actually ask

How do I check my Claude Code session and weekly limit?

Install AI Limits and log in to Claude Code as usual. When AI Limits asks to read the Claude Code sign-in, allow it: the question names the file and where its token goes. The widget then shows the 5-hour session and the weekly window with live percentages and reset countdowns. On plans that have them, the Fable, Opus and Sonnet weeks can be rows of their own.

Does it need API keys?

No. It reads the logins your tools already have: Claude Code, Codex CLI, the gh CLI, the Antigravity CLI (agy) and the Grok CLI, each only once you allow it. Cursor has no sign-in for other apps, so AI Limits signs in to Cursor once with a session of its own, from Cursor's Sign-in in Settings: Cursor's own sign-in page opens in your browser, and the editor's sign-in is never read. The tokens are used read-only and never rotated, so your tools stay logged in. A key or usage token you paste is an optional extra path, chosen under the provider's Sign-in in Settings and stored in Windows Credential Manager, never in a config file.

Does it read anything before I allow it?

No. A fresh install reads nothing. On the first start a welcome lists the tools detected on this PC, found only by whether their folder exists, with nothing inside opened, and names each file it would read and where each token goes. Allow starts the selected tools; Cancel reads nothing. Any other tool asks once, the same way. Clearing a tool's rows pauses it, and selecting them again asks nothing; Forget permission under its Sign-in takes the permission back. An update from 0.7.0 keeps what worked and lists every file read in one window. Antigravity's question also says that Google has suspended some accounts for using Antigravity's sign-in outside Antigravity: AI Limits only reads the quota, once per update, but the risk is yours. The privacy page lists every file and host.

Which providers are supported?

Claude (Anthropic), OpenAI Codex via a ChatGPT subscription, GitHub Copilot including premium requests, Google Antigravity, xAI Grok (the weekly SuperGrok limit) and Cursor (the subscription's included usage). Each one is switched on by selecting its rows in Settings, where its sign-in is chosen too; a provider with every row cleared, or not allowed, makes no network requests. Antigravity needs the Antigravity CLI: its sign-in is renewed only when you run agy, not by the Antigravity editor, so until then the row reads token expired.

What is the Settings window?

Right-click the widget and open Settings. On its Providers tab every row is in one list with a Widget, a Tooltip and a Taskbar column: the widget and the taskbar panel's tooltip are chosen separately, and the Taskbar column picks the two providers the panel and the tray icon show. On its Display tab, Percentage, Time to reset and Progress bar choose what each row shows on the widget, the tooltip and the taskbar panel: the percentage, the time until its limit resets, the bar, in any mix; without the bar the widget and the panel get smaller. Extra rows cover what a provider meters on its own: Claude's Fable, Opus and Sonnet weeks on plans that have them, Antigravity's Claude and GPT pool, Grok Build and Cursor's Grok Bot. Once a provider has answered, only the rows it reports are offered. Under each provider's rows, its Sign-in chooses where the token comes from: the tool's own sign-in or a key or token you paste, and only the one chosen is used. Each tool is asked once: clearing its rows pauses it, Forget permission takes the permission back. Model, Version and Reasoning effort add the model a tool is using to its row, for example Opus 5.5 · xhigh, and any model can be given a name of your own. A tick shows at once.

Does it slow the PC down?

Measured, not estimated: an automated audit of the 0.7.1 release build records 0.014% of one CPU core, no GPU engine time at all, a working set around 53 MB, about 10 threads and no raised timer resolution. Polling pauses once there has been no input for five minutes, a locked PC included, and picks up again when you are back.

Is it free?

Yes. Open source under GPL-3.0; the code, releases and issue tracker live on GitHub.

Does it show GitHub Copilot premium requests?

Yes. The Copilot rows show the premium requests, chat and completions quotas with the date each one resets, read from the same endpoint the Copilot extensions use. Plans billed in AI Credits are read too; a quota the plan does not have is left out.

What does the tray icon show?

Two concentric rings for the same two providers as the taskbar panel, by default the first two in the widget, the busier one on the outer ring, both sweeping clockwise from 12 o'clock. A value too small for an arc becomes a dot, and only a true 100% closes the ring, so the shape never lies. It is one of two indicators: the alternative is the taskbar panel, which paints two providers onto the bar as digits and bars, as the time until each limit resets, or both. The Taskbar column of Settings picks which two providers the panel and the rings show. You pick the indicator from the Taskbar submenu.

Can I see a look before I choose it?

Yes. Rest the pointer on a detail level, a layout, a width, a column layout, Usage forecast, a palette, Monochrome, an opacity, a brightness or a saturation in the context menu, and the widget, the taskbar panel and the tray icon show it at once. A click keeps it; closing the menu without one puts back what was there. Nothing is saved until the click.

How does it update itself?

With Automatic updates on, as it is by default, a copy from the installer checks GitHub for a newer release, checks the download against the SHA-256 GitHub publishes and against the release's Ed25519 signature, and installs it only once you have been away for five minutes (no input, or the session locked). Microsoft Store, Scoop and portable copies never contact GitHub: their own channel updates them. Requests follow the proxy set in Windows.
